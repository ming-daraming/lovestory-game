# 상훈 ♥ 민영 모바일 청첩장 게임

파일 하나(index.html)로 동작하는 픽셀 게임입니다. 빌드 과정이 없습니다.

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들고 이 폴더의 파일(index.html, README.md)을 올립니다.
2. 저장소 Settings > Pages > Branch: main / (root) 선택 후 Save
3. 1~2분 뒤 https://<아이디>.github.io/<저장소이름>/ 에서 게임이 열립니다.

## Netlify / Vercel
폴더를 통째로 드래그 앤 드롭하면 바로 배포됩니다.

## 청첩장과 연결
- 청첩장 사이트에 "게임하러 가기" 버튼을 만들고 위에서 만든 게임 주소로 연결합니다.
- 청첩장 프로젝트(Lovable 등)의 public 폴더에 넣을 경우 index.html을 game.html 등으로 이름을 바꿔 넣고
  <청첩장주소>/game.html 로 열리는지 확인하세요.

## 수정 위치
- 게임 안의 '모바일 청첩장 보러가기' 링크: index.html 안의 https://minyoung-sanghun-wedding.lovable.app 를 검색해서 바꾸면 됩니다.
